   Complete Working DemonstrationHere is a unified program combining constructors, 
   constructor chaining with this, and static counters:
   Javaclass Book {
    // Static variable: shared by all instances
    static int bookCount = 0;

    // Instance variables: unique to each object
    String title;
    double price;

    // Static initialization block
    static {
        System.out.println("Book class loaded. Tracking inventory...\n");
    }

    // Default/no-arg constructor chaining to the parameterized one
    Book() {
        this("Untitled", 0.0); // calls Book(String, double)
    }

    // Parameterized constructor
    Book(String title, double price) {
        this.title = title; // 'this' resolves variable shadowing
        this.price = price;
        bookCount++;        // increments shared class-level counter
    }

    // Instance method
    void printDetails() {
        System.out.println("Title: " + this.title + " | Price: ₹" + this.price);
    }

    // Static utility method
    static void displayTotalBooks() {
        // Can access static members, but CANNOT access 'this.title' or 'price'
        System.out.println("Total books registered: " + bookCount);
    }
}

public class Main {
    public static void main(String[] args) {
        // 1. Using parameterized constructor
        Book b1 = new Book("Effective Java", 1250.0);
        b1.printDetails();

        // 2. Using no-arg constructor (which chains via this())
        Book b2 = new Book();
        b2.printDetails();

        // 3. Another instance
        Book b3 = new Book("Clean Code", 1400.0);
        b3.printDetails();

        System.out.println("-----------------------------------");

        // 4. Invoking static method via Class name directly
        Book.displayTotalBooks();
    }
}

2. The static Keyword
What is it?
static marks a member as belonging to the class itself, not to any single instance/object.

Memory is allocated once in the Metaspace/Method Area when the class is loaded by the JVM.

All objects of that class share the exact same copy.

Instance vs. Static Variables
Instance variable:  Object 1 [x = 10]    Object 2 [x = 20]
Static variable:    Shared by all ---> [companyName = "Infosys"]
Code Example
Java
class Student {
    int rollNo;                    // Instance variable: unique per student
    static String college = "VTU"; // Static variable: shared across all students

    Student(int rollNo) {
        this.rollNo = rollNo;
    }

    void display() {
        System.out.println("Roll No: " + rollNo + " | College: " + college);
    }
}

public class StaticVarDemo {
    public static void main(String[] args) {
        Student s1 = new Student(101);
        Student s2 = new Student(102);

        s1.display(); // Roll No: 101 | College: VTU
        s2.display(); // Roll No: 102 | College: VTU

        // Changing via class name affects ALL instances
        Student.college = "IIT";

        s1.display(); // Roll No: 101 | College: IIT
        s2.display(); // Roll No: 102 | College: IIT
    }
}
Quick Revision Points
Access syntax: ClassName.variableName (preferred over object.variableName).

Saves memory: avoids duplicating common values across thousands of objects.

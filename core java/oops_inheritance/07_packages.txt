Packages in Java (Easy Explanation)
Real-Life Analogy
Think of packages like labeled folders on your computer:

Instead of dumping all your documents, vacation photos, and college assignments on your Desktop, you make separate folders: Documents, Photos, and College_Assignments.

In Java, a package is simply a folder that groups related classes together.

Why Do We Need Packages?
Avoid Name Clashes:
Two people can have the exact same file name Notes.txt as long as they are in different folders. Similarly, Java has two Date classes:

java.util.Date (for normal calendar dates)

java.sql.Date (for database dates)
Because they are in separate packages, there is no clash!

Organize Large Projects:
Keeps code structured:

Plaintext
src/
└── com/
    └── shop/
        ├── auth/         (UserLogin.java, Register.java)
        ├── cart/         (CartItem.java, Checkout.java)
        └── payment/      (UpiPay.java, CardPay.java)
Control Access:
Allows classes inside the same package to talk freely without exposing everything to the outside world.

How to Use Packages (Syntax & Examples)
1. Creating a Package: package keyword
Put it as the very first line in your .java file:

Java
package com.shop.payment;

public class UpiPay {
    public void pay() {
        System.out.println("Payment done via UPI!");
    }
}
2. Using Classes From Another Package: import keyword
If you are in Main.java and want to use UpiPay:

Java
package com.shop;

// Import the specific class
import com.shop.payment.UpiPay;

// Or import all classes from that folder using '*'
// import com.shop.payment.*;

public class Main {
    public static void main(String[] args) {
        UpiPay payment = new UpiPay();
        payment.pay();
    }
}
Types of Packages
Built-in Packages (Provided by Java):

java.lang (Automatically imported: System, String, Math)

java.util (Data structures: Scanner, ArrayList)

java.io (Files and input/output)

User-Defined Packages:

Packages you create yourself to organize your project files.
